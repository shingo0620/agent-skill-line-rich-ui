# LINE File Delivery Guide (via Google Drive)

Since LINE Messaging API requires a public HTTPS URL for file messages, use this workflow to deliver files generated by the agent.

## Workflow

1. **Generate the file**: Save the content to a local path (e.g., `/tmp/output.txt`).
2. **Upload to Drive**: Use `gog drive upload /tmp/output.txt --parent <FOLDER_ID>`.
3. **Set Permissions**: Run `gog drive share <FILE_ID> --anyone --role reader`.
4. **Notify User**: Send a message with a link.

## Delivery Options

### Option A: Button (Recommended)
Cleanest UI. Directs user to Google's mobile-friendly viewer.
`[[buttons: File Ready | Click to view the document. | Open:https://drive.google.com/file/d/FILE_ID/view]]`

### Option B: Markdown Table
Good for multiple files.
| File Name | Link |
| :--- | :--- |
| Report.pdf | [View](https://drive.google.com/file/d/FILE_ID/view) |

### Option C: Direct Download Link (Legacy)
Note: May trigger safety warnings or fail to open in some mobile browsers.
URL: `https://drive.google.com/uc?export=download&id=FILE_ID`
